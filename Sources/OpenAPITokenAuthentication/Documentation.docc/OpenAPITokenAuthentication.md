# ``OpenAPITokenAuthentication``

Access-token authentication and automatic refresh for clients generated by Swift OpenAPI Generator.

## Overview

An ``AuthenticationSession`` actor holds a person's credentials and shares in-flight sign-in and
refresh work between callers. ``AuthenticationMiddleware`` is a `ClientMiddleware` that attaches
the session's access token as a bearer token, and refreshes and retries a replayable request once
when the response asks for it.

The API's own sign-in and refresh calls are an ``AuthenticationClient`` you implement over the
generated client, returning an ``AuthenticationResponse``. The session keeps credentials in an
``AuthenticationStorage``; ``InMemoryAuthenticationStorage`` keeps them for the life of the
process, and a Keychain-backed storage keeps them across restarts.

## Example

```swift
import OpenAPITokenAuthentication

let session = AuthenticationSession(
    client: authenticationClient,
    storage: InMemoryAuthenticationStorage<YourAuthenticationResponse>()
)

try await session.authenticate(credentials: credentials)

let client = Client(
    serverURL: serverURL,
    transport: transport,
    middlewares: [AuthenticationMiddleware(session: session)]
)
```
